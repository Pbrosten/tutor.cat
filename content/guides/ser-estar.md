title: Ser i estar
exercises: [ser-estar]

El català traça la frontera en un lloc diferent del castellà. El verb per defecte és **ser**; **estar** és el marcat.

## ser

| | |
|---|---|
| identitat, professió, nacionalitat, origen | **Soc** metge. **És** de Lleida. **Som** catalans. |
| característiques | La casa **és** gran. En Pere **és** simpàtic. |
| hora, dates, esdeveniments | **Són** les deu. Avui **és** dilluns. La reunió **és** a les cinc. |
| **localització de persones i coses** (on és X?) | La Maria **és** a casa. Les claus **són** a la taula. On **és** el lavabo? |
| possessió | Aquest cotxe **és** meu. |
| lloc d'un esdeveniment | El concert **és** a la plaça. |

## estar

| | |
|---|---|
| estat temporal / resultat, amb adjectiu o participi | **Estic** cansat. La porta **està** oberta. El got **està** trencat. |
| **estar + gerundi** (en curs) | **Estem** sopant. |
| localització **amb durada** (quedar-se, passar-hi un temps) | **Vaig estar** dos anys a Londres. **Estaré** aquí fins dilluns. |
| *estar-se* = viure, allotjar-se | **S'està** a can Roca. |
| benestar, ànim, salut | Com **estàs**? **Estic** bé / malalt / content. |
| estat civil, situació laboral | **Està** casada. **Està** a l'atur. |
| **estar de** + nom | **Estem de** vacances. **Està de** bon humor. |
| *estar per* + inf. (pendent) | El sopar **està per** fer. |

El parany: per dir *on és algú ara mateix*, el català fa servir **ser**: *Ara **soc** a la feina* (no *estic*). *Estic a la feina* se sent pertot a Barcelona i s'accepta com a col·loquial, però a l'examen volen *soc*. Fes servir **estar** per a la localització només quan la idea és *quedar-s'hi una temporada*: *Aquesta setmana **estic** a Madrid.*

## Adjectius que canvien de sentit

| ser | estar |
|---|---|
| **ser bo** (bo per naturalesa, de bona qualitat) | **estar bo** (té bon gust ara / té salut / és atractiu) |
| **ser llest** (intel·ligent) | **estar llest** (a punt) |
| **ser tranquil** (persona calmada) | **estar tranquil** (calmat ara) |
| **ser viu** (espavilat) | **estar viu** (no mort) |
| **ser negre** (de color negre) | **estar negre** (furiós) |

## Exemples

- El sopar **és** a les nou; els convidats ja **són** aquí. Jo encara **estic** cuinant.
- Ell **és** molt nerviós, però avui **està** tranquil.
- On **és** el Joan? — **És** a Londres; **hi està** una setmana per feina.
