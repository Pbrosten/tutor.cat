## Gerund

**-ar → -ant, -er/-re → -ent, -ir → -int**: *cantant, perdent, dormint, servint*.

Irregulars follow the stem of the 1st person plural: **dient, fent, veient, duent, bevent, caient, creient, rient, coneixent, escrivint, vivint, sabent, tenint, venint, podent, volent, sent (essent)**.

Uses:

| | |
|---|---|
| in progress: *estar* + gerund | **Estic** llegint. |
| simultaneous action / manner | Va sortir **cantant**. Ho vaig aprendre **practicant**. |
| *tot* + gerund (while) | **Tot caminant**, parlàvem de la feina. |
| *anar / continuar / seguir* + gerund | **Va millorant**. **Continua plovent**. |

Two errors the exam looks for:

1. **Gerundi de posterioritat** — a gerund cannot express what happens *after*: ✗ *Va caure, trencant-se la cama* → ✓ *Va caure **i es va trencar** la cama.*
2. **Gerund as adjective** — ✗ *una caixa contenint llibres* → ✓ *una caixa **que conté** llibres*; ✗ *aigua bullint* → ✓ *aigua **bullent***.

Pronouns attach: *llegint**-lo**, rentant**-se**, dient**-m'ho***.

## Participle

**-ar → -at, -er/-re → -ut, -ir → -it**: *cantat, perdut, dormit*. Four forms: *cantat, cantada, cantats, cantades*.

Irregulars: **fet, dit, vist, obert, cobert, ofert, sofert, escrit, mort, pres, après, comprès, entès, atès, encès, estès, cuit, dut, tret, absolt, resolt, romàs, nascut, viscut, tingut, vingut, pogut, volgut, sabut, begut, rebut, cregut, caigut, estat (ser / estar), sigut (ser, col.)**.

Uses:

| | agreement |
|---|---|
| compound tenses with *haver* | none (optionally with *la / les / el / els*: *l'he vist**a***) |
| *ser* passive | with the subject: *Van ser **rebudes** pel director.* |
| *estar* + participle (state) | with the subject: *Les finestres **estan** obert**es**.* |
| as an adjective | with the noun: *una carta **escrita** a mà* |
| absolute clause | *Acabada la reunió, vam marxar.* |

## Examples

- **Havent** sopat, vam sortir a passejar. (having…, formal)
- La roba **estesa** encara **està** mullada.
- **Estic** buscant les ulleres — les he **deixades** (deixat) al cotxe.
