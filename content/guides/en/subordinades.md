## Cause (why?)

| | mood | example |
|---|---|---|
| **perquè** | indicative | No surto **perquè** plou. |
| **ja que** | indicative | **Ja que** ets aquí, ajuda'm. |
| **com que** (sentence-initial) | indicative | **Com que** plovia, no vam sortir. |
| **per** + infinitive | | El van multar **per** anar massa ràpid. |

*Com que* goes first, *perquè* goes second: **Com que** plou, no surto. = No surto **perquè** plou. (Never *perquè* at the start with this meaning — that's the question *per què?*)

## Purpose (what for?)

| | mood | example |
|---|---|---|
| **perquè** | subjunctive | T'ho explico **perquè ho entenguis**. |
| **per** + infinitive (same subject) | | Vaig al mercat **per comprar** fruita. |
| **per tal que / a fi que** | subjunctive | Truca **per tal que** ho sàpiguen. |

So **perquè** + indicative = *because*; **perquè** + subjunctive = *so that*.

## Time (when?)

| | mood | example |
|---|---|---|
| **quan** | indicative (present, past) / **subjunctive** (future) | **Quan** arribo, sopo. · **Quan arribi**, soparé. |
| **mentre** | indicative / subjunctive (future) | **Mentre** cuino, escolto música. |
| **abans de** + inf. / **abans que** + subj. | | **Abans de** sortir… / **Abans que** surtis… |
| **després de** + inf. / **després que** + ind. | | **Després de** sopar… / **Després que** va marxar… |
| **fins que** | subjunctive (future) | Espera **fins que** jo torni. |
| **des que** | indicative | **Des que** viu aquí, està més content. |
| **tan bon punt / així que** | subjunctive (future) | **Tan bon punt** ho sàpiga, t'ho diré. |
| **sempre que** | indicative (whenever) | **Sempre que** ve, porta pastís. |

The pattern: a time clause about the **future** takes the **present subjunctive**, never the future tense.

## Concession and consequence

- **encara que / tot i que / malgrat que** + indicative (fact) or subjunctive (hypothesis): *Encara que plou, sortim. / Encara que plogui, sortirem.*
- **tan … que**, **tant … que**: *Estava **tan** cansat **que** es va adormir.*
- **així que / de manera que**: *Va ploure molt, **així que** ens vam quedar a casa.*
