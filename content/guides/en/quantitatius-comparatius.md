## Quantifiers

| | forms | notes |
|---|---|---|
| molt | molt, molta, molts, moltes | agrees: *molta gent, molts llibres* |
| poc | poc, poca, pocs, poques | |
| bastant | bastant, bastants | no feminine form |
| tant | tant, tanta, tants, tantes | |
| quant | quant, quanta, quants, quantes | questions: *Quantes hores?* |
| massa, força, prou, més, menys | invariable | *massa gent, força llibres, prou temps* |
| gaire | gaire, gaires | only in negatives, questions, conditions: *No tinc gaire temps. Tens gaires amics?* |
| gens (de) | invariable | uncountable, negative: *No tinc gens de gana.* |
| cap | invariable | countable, negative: *No tinc cap germà.* |
| algun | algun, alguna, alguns, algunes | |
| tot | tot, tota, tots, totes | *tot el dia, tota la nit, tots els dies* |
| cada | invariable | *cada dia* |
| uns quants / unes quantes | | a few |

*Molt* as an adverb is invariable: *Treballa molt.* / *molt cansada*. Countable vs uncountable: **cap** poma / **gens de** pa; **gaires** pomes / **gaire** pa.

## Comparison

| | | |
|---|---|---|
| more than | **més … que** | La Marta és **més** alta **que** jo. |
| less than | **menys … que** | Tinc **menys** feina **que** tu. |
| as … as (adj./adv.) | **tan … com** | És **tan** alt **com** tu. |
| as much/many … as (noun/verb) | **tant(a/s/es) … com** | Té **tants** llibres **com** jo. Treballa **tant com** tu. |
| same as | **igual de … que** / **el mateix … que** | És **igual d'**alt **que** tu. |

Irregulars: **millor** (més bo), **pitjor** (més dolent), **major / menor** (size, age formal), **superior / inferior**.

Superlative: **el/la més … de** — *la ciutat més gran de Catalunya*; **-íssim**: *boníssim, grandíssim, moltíssim*.

Before a number: *més **de** cent persones*, *menys **de** deu euros*.

## Examples

- No hi ha **gaire** gent, però hi ha **massa** soroll.
- No queda **gens de** llet ni **cap** ou.
- Aquest restaurant és **millor que** l'altre, i **molt més** barat.
- Corre **tant com** pot, però no és **tan** ràpid **com** el seu germà.
