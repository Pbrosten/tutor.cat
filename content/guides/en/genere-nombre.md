## Feminine from masculine

| rule | examples |
|---|---|
| add **-a** | noi → noia, senyor → senyora, amic → amiga |
| **-e / -o → -a** | alumne → alumna, mosso → mossa |
| stressed vowel → **-na** | germà → germana, veí → veïna, cosí → cosina |
| **-t → -da**, **-c → -ga**, **-s → -ssa** | nebot → neboda, amic → amiga, gos → gossa |
| **-u → -va** | esclau → esclava, nou → nova, viu → viva |
| **-òleg → -òloga** | psicòleg → psicòloga |
| **-or → -ora** | director → directora (but actor → actriu) |
| invariable | estudiant, artista, periodista, jove, cantant, pacient |
| different word | home / dona, pare / mare, marit / muller, gendre / nora, cavall / euga |

Gender traps: words in **-a** that are masculine (*el dia, el mapa, el problema, el sistema, el clima, el planeta*) and words that differ from Spanish/English: **la sal, la calor, la llet, la dent, la sang, la suor, la resta, el front, el llum (lamp) / la llum (light), el son (sleep) / la son (sleepiness), el compte, el senyal, el dubte, els afores, l'avantatge (m.), el costum, el pendent (m.)**.

## Plural

| rule | examples |
|---|---|
| add **-s** | cotxe → cotxes, taula → taules |
| **-a → -es** (with spelling changes) | casa → cases, va**ca** → va**ques**, pla**ça** → pla**ces**, ami**ga** → ami**gues**, plat**ja** → plat**ges**, llen**gua** → llen**gües**, pas**qua** → pas**qües** |
| stressed vowel → **-ns** | germà → germans, camió → camions, pa → pans, mà → mans |
| but some take **-s** only | sofà → sofàs, cafè → cafès, papà → papàs, bebè → bebès |
| masc. in **-s, -ç, -x, -ix, -sc, -st, -xt → -os** | gas → gasos, braç → braços, reflex → reflexos, peix → peixos, disc → discos, gust → gustos (gusts), text → textos (texts) |
| invariable | dilluns, dimarts, dijous, llapis, temps, fons, globus, cactus, virus, atles |
| **-ig → -igs / -jos** | passeig → passeigs / passejos, mig → mitjos |

Adjectives follow the same rules. Four-form adjectives agree fully: *bonic, bonica, bonics, boniques; verd, verda, verds, verdes*. Two-form adjectives have one form for both genders: *gran/grans, jove/joves, feliç/feliços, difícil/difícils, amable/amables*.
