Catalan draws the line differently from Spanish. The default verb is **ser**; **estar** is the marked one.

## ser

| | |
|---|---|
| identity, profession, nationality, origin | **Soc** metge. **És** de Lleida. **Som** catalans. |
| characteristics (also of people: tall, nice, tired-looking?) | La casa **és** gran. En Pere **és** simpàtic. |
| time, dates, events | **Són** les deu. Avui **és** dilluns. La reunió **és** a les cinc. |
| **location of people and things** (where is X?) | La Maria **és** a casa. Les claus **són** a la taula. On **és** el lavabo? |
| possession | Aquest cotxe **és** meu. |
| where an event takes place | El concert **és** a la plaça. |

## estar

| | |
|---|---|
| temporary state / result, with an adjective or participle | **Estic** cansat. La porta **està** oberta. El got **està** trencat. |
| **estar + gerund** (in progress) | **Estem** sopant. |
| location **with duration** (stay, spend time) | **Vaig estar** dos anys a Londres. **Estaré** aquí fins dilluns. |
| *estar-se* = live, stay | **S'està** a can Roca. |
| well-being, mood, health | Com **estàs**? **Estic** bé / malalt / content. |
| civil state, job situation | **Està** casada. **Està** a l'atur. |
| **estar de** + noun | **Estem de** vacances. **Està de** bon humor. |
| *estar per* + inf. (still to do) | El sopar **està per** fer. |

The trap: for *where somebody is right now*, Catalan says **ser**: *Ara **soc** a la feina* (not *estic*). *Estic a la feina* is everywhere in Barcelona and is accepted as colloquial, but the exam wants *soc*. Use **estar** for location only when the idea is *staying for a while*: *Aquesta setmana **estic** a Madrid.*

## Adjectives that switch meaning

| ser | estar |
|---|---|
| **ser bo** (good, tasty by nature) | **estar bo** (tastes good now / is healthy / is attractive) |
| **ser llest** (clever) | **estar llest** (ready) |
| **ser tranquil** (calm person) | **estar tranquil** (calm now) |
| **ser viu** (alive; sharp) | **estar viu** (alive, not dead) |
| **ser negre** (black) | **estar negre** (furious) |

## Examples

- El sopar **és** a les nou; els convidats ja **són** aquí. Jo encara **estic** cuinant.
- Ell **és** molt nerviós, però avui **està** tranquil.
- On **és** el Joan? — **És** a Londres; **hi està** una setmana per feina.
