---
title: Perífrasis verbals
exercises: [perifrasis]
---
A periphrasis = auxiliary verb (+ preposition) + infinitive / gerund / participle. Weak pronouns go before the auxiliary or after the infinitive: *ho he de fer* = *he de fer-ho*.

## Obligation and need

| | | |
|---|---|---|
| **haver de** + inf. | personal obligation | **He d'**estudiar. **Hem de** marxar. |
| **caldre** + inf. / **cal que** + subj. | impersonal need | **Cal** estudiar més. **Cal que** estudiïs. |
| **s'ha de** + inf. | impersonal, "one must" | Aquí **s'ha de** parlar fluix. |

*Tenir que* does not exist in Catalan. *Deure* + infinitive is not obligation, it is **probability**: *Deu ser tard* = it must be (probably is) late.

## Ability, will, permission

**poder** + inf. (*Puc entrar?*), **voler** + inf. (*Vull dormir*), **saber** + inf. (know how: *Sé nedar*).

## Phases of an action

| | | |
|---|---|---|
| **començar a** + inf. | start | **Comença a** ploure. |
| **estar a punt de** + inf. | about to | **Estic a punt d'**acabar. |
| **estar** + gerund | in progress | **Estic** llegint. |
| **continuar** + gerund / **seguir** + gerund | continue | **Continua** plovent. |
| **acabar de** + inf. | have just | **Acabo d'**arribar. |
| **deixar de** + inf. | stop | **Ha deixat de** fumar. |
| **tornar a** + inf. | again | **Torna a** trucar més tard. |
| **anar** + gerund | gradually | **Va** millorant. |
| **acabar** + gerund | end up | **Va acabar** plorant. |

Note the two meanings of *acabar*: **acabar de** + inf. = *have just*; **acabar** + gerund = *end up*.

## Examples

- No **puc** venir: **haig de** treballar. (*haig de* = *he de*)
- **Acabem de** sopar, ara **estem** rentant els plats.
- **Cal que** portis el passaport. / **Cal** portar el passaport.
- **Deuen** ser les vuit — no, ja **han de** ser les nou.
