Three patterns cover B1. The **si** clause never takes the future or the conditional.

| type | si + … | main clause | example |
|---|---|---|---|
| real / likely | **present indicative** | present, future, imperative | Si **plou**, no **sortirem**. Si **tens** gana, **menja**. |
| hypothetical / unlikely | **imperfet de subjuntiu** | **condicional** | Si **tingués** diners, **viatjaria**. |
| impossible past (B2) | plusquamperfet de subjuntiu | condicional perfet | Si **hagués estudiat**, **hauria aprovat**. |

- Si **vols**, t'**ajudo**. (real, present)
- Si **acabes** aviat, **truca'm**. (real, imperative)
- Si **fos** ric, no **treballaria**. (hypothetical)
- Què **faries** si **guanyessis** la loteria? (hypothetical)

Common errors: *si tindré* ✗ → *si tinc*; *si tindria* ✗ → *si tingués*; *si tingués… tindré* ✗ → *tindria*.

## Other conditional connectors

| | mood | |
|---|---|---|
| **en cas que** | subjunctive | **En cas que** plogui, ho farem dins. |
| **sempre que / mentre** (provided that) | subjunctive | Vine **sempre que** vulguis. |
| **si no** | | Afanya't; **si no**, perdrem el tren. |
| **llevat que / tret que** (unless) | subjunctive | Hi anirem, **llevat que** plogui. |
| **amb la condició que** | subjunctive | T'ho deixo **amb la condició que** m'ho tornis. |

The order of the clauses is free: *No sortirem si plou.* The comma appears only when *si* goes first.
