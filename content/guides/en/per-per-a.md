---
title: Per i per a
exercises: [per-per-a]
---
**per** looks backwards (cause, means, route, exchange); **per a** looks forward (purpose, destination, recipient). In Central Catalan, before an **infinitive** *per* is used for both — that simplifies things.

## per

| meaning | example |
|---|---|
| cause, reason (because of) | Ho faig **per** tu. Va tancar **per** la pluja. |
| agent (passive) | Va ser escrit **per** Rodoreda. |
| means | **Per** correu, **per** telèfon, **per** internet. |
| route, through | Passem **pel** parc. Entra **per** la porta del darrere. |
| approximate time / frequency | **Per** Nadal. Dos cops **per** setmana. **Pel** matí (col.), *al matí* (std). |
| exchange, price | Ho vaig comprar **per** deu euros. |
| in place of, on behalf of | Signa **per** mi. |
| "still to" | Està **per** fer. |
| purpose **before an infinitive** (Central) | Vinc **per** parlar amb tu. Estudio **per** aprovar. |

## per a

| meaning | example |
|---|---|
| recipient, beneficiary (for someone) | Un regal **per a** la Maria. És **per a** tu. |
| purpose / use of a thing (for something) | Una crema **per a** les mans. Roba **per a** nens. |
| destination | El tren **per a** Girona. |
| deadline | Els deures són **per a** dilluns. |
| opinion / point of view | **Per a** mi, això és un error. |

Contractions: *per + el* = **pel**, *per + els* = **pels**, *per a + el* = **per al**, *per a + els* = **per als**: *un llibre **per al** nen*.

## Tests

- Answers *per què?* (why?) → **per**. Answers *per a què / per a qui?* (what for? for whom?) → **per a**.
- Before a person or thing that *receives*: **per a**. Before a person who is the *reason*: **per**. Compare: *Ho faig **per** tu* (because of you) vs *És **per a** tu* (it's for you).
- Before an infinitive: **per** (in Barcelona usage). The IEC also accepts *per a* + infinitive when there is no action verb before it (*un producte per a netejar vidres*), but *per* is never wrong here.

## Related forms

**per què** (why? — question, two words with accent) · **perquè** (because / so that — one word) · **per a què** (what for?) · **el perquè** (the reason, noun).
