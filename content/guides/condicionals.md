Tres patrons cobreixen el B1. L'oració amb **si** no porta mai futur ni condicional.

| tipus | si + … | oració principal | exemple |
|---|---|---|---|
| real / probable | **present d'indicatiu** | present, futur, imperatiu | Si **plou**, no **sortirem**. Si **tens** gana, **menja**. |
| hipotètica / poc probable | **imperfet de subjuntiu** | **condicional** | Si **tingués** diners, **viatjaria**. |
| impossible en el passat (B2) | plusquamperfet de subjuntiu | condicional perfet | Si **hagués estudiat**, **hauria aprovat**. |

- Si **vols**, t'**ajudo**. (real, present)
- Si **acabes** aviat, **truca'm**. (real, imperatiu)
- Si **fos** ric, no **treballaria**. (hipotètica)
- Què **faries** si **guanyessis** la loteria? (hipotètica)

Errors habituals: *si tindré* ✗ → *si tinc*; *si tindria* ✗ → *si tingués*; *si tingués… tindré* ✗ → *tindria*.

## Altres connectors condicionals

| | mode | |
|---|---|---|
| **en cas que** | subjuntiu | **En cas que** plogui, ho farem dins. |
| **sempre que / mentre** (a condició que) | subjuntiu | Vine **sempre que** vulguis. |
| **si no** | | Afanya't; **si no**, perdrem el tren. |
| **llevat que / tret que** (excepte si) | subjuntiu | Hi anirem, **llevat que** plogui. |
| **amb la condició que** | subjuntiu | T'ho deixo **amb la condició que** m'ho tornis. |

L'ordre de les oracions és lliure: *No sortirem si plou.* La coma només hi va quan *si* encapçala la frase.
