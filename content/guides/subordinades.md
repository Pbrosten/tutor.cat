## Causa (per què?)

| | mode | exemple |
|---|---|---|
| **perquè** | indicatiu | No surto **perquè** plou. |
| **ja que** | indicatiu | **Ja que** ets aquí, ajuda'm. |
| **com que** (a l'inici) | indicatiu | **Com que** plovia, no vam sortir. |
| **per** + infinitiu | | El van multar **per** anar massa ràpid. |

*Com que* va al principi, *perquè* va després: **Com que** plou, no surto. = No surto **perquè** plou. (Mai *perquè* al principi amb aquest sentit — això és la pregunta *per què?*)

## Finalitat (per a què?)

| | mode | exemple |
|---|---|---|
| **perquè** | subjuntiu | T'ho explico **perquè ho entenguis**. |
| **per** + infinitiu (mateix subjecte) | | Vaig al mercat **per comprar** fruita. |
| **per tal que / a fi que** | subjuntiu | Truca **per tal que** ho sàpiguen. |

Per tant, **perquè** + indicatiu = causa; **perquè** + subjuntiu = finalitat.

## Temps (quan?)

| | mode | exemple |
|---|---|---|
| **quan** | indicatiu (present, passat) / **subjuntiu** (futur) | **Quan** arribo, sopo. · **Quan arribi**, soparé. |
| **mentre** | indicatiu / subjuntiu (futur) | **Mentre** cuino, escolto música. |
| **abans de** + inf. / **abans que** + subj. | | **Abans de** sortir… / **Abans que** surtis… |
| **després de** + inf. / **després que** + ind. | | **Després de** sopar… / **Després que** va marxar… |
| **fins que** | subjuntiu (futur) | Espera **fins que** jo torni. |
| **des que** | indicatiu | **Des que** viu aquí, està més content. |
| **tan bon punt / així que** | subjuntiu (futur) | **Tan bon punt** ho sàpiga, t'ho diré. |
| **sempre que** | indicatiu (cada vegada que) | **Sempre que** ve, porta pastís. |

El patró: una oració temporal referida al **futur** va en **present de subjuntiu**, mai en futur.

## Concessió i conseqüència

- **encara que / tot i que / malgrat que** + indicatiu (fet) o subjuntiu (hipòtesi): *Encara que plou, sortim. / Encara que plogui, sortirem.*
- **tan … que**, **tant … que**: *Estava **tan** cansat **que** es va adormir.*
- **així que / de manera que**: *Va ploure molt, **així que** ens vam quedar a casa.*
