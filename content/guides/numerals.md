## Cardinals

| | | | |
|---|---|---|---|
| 1 u / un / una | 11 onze | 21 vint-i-u(n) / vint-i-una | 100 cent |
| 2 dos / dues | 12 dotze | 22 vint-i-dos / vint-i-dues | 101 cent u |
| 3 tres | 13 tretze | 30 trenta | 200 dos-cents / dues-centes |
| 4 quatre | 14 catorze | 31 trenta-u(n) | 300 tres-cents |
| 5 cinc | 15 quinze | 40 quaranta | 500 cinc-cents |
| 6 sis | 16 setze | 50 cinquanta | 1.000 mil |
| 7 set | 17 disset | 60 seixanta | 2.000 dos mil |
| 8 vuit | 18 divuit | 70 setanta | 1.000.000 un milió |
| 9 nou | 19 dinou | 80 vuitanta | 2.000.000 dos milions |
| 10 deu | 20 vint | 90 noranta | 1.000.000.000 mil milions |

- **u** per comptar / **un** davant d'un nom masculí / **una** davant d'un femení: *pàgina u, un noi, una noia, vint-i-una noies*.
- **dos / dues**, **dos-cents / dues-centes** concorden en gènere: *dues cases, dues-centes persones*. Només l'1, el 2 i les centenes concorden.
- **Guionets: D-U-C** — entre desenes i unitats (*vint-i-dos, trenta-quatre, noranta-nou*) i entre unitats i centenes (*dos-cents, tres-cents*). Enlloc més: *dos-cents trenta-quatre, mil dos-cents, tres mil cinc-cents vint-i-u*.
- *vint* porta **-i-**: *vint-i-tres*; les altres desenes, no: *trenta-tres*.
- Els milers se separen amb punt i els decimals amb coma: *1.500,50 €* — *mil cinc-cents euros amb cinquanta cèntims*.

## Ordinals

| | | |
|---|---|---|
| 1r primer / 1a primera | 5è cinquè / 5a cinquena | 10è desè |
| 2n segon / 2a segona | 6è sisè | 11è onzè |
| 3r tercer / 3a tercera | 7è setè | 20è vintè |
| 4t quart / 4a quarta | 8è vuitè | 21è vint-i-unè |
| | 9è novè | 100è centè |

Plural: *primers, primeres, segons, cinquens, cinquenes*. Abreviatures: **1r, 1a, 2n, 2a, 3r, 3a, 4t, 4a**, i després **-è / -a**: *5è, 5a, 12è*. *Visc al tercer pis, segona porta (3r 2a).*

Les dates van amb cardinals: *el 3 de maig*, excepte el primer: *l'1 (u) de maig*. Reis i segles també: *Jaume I (primer)*, *el segle XXI (vint-i-u)*.

## Fraccions, múltiples, percentatges

*mig / mitja* (½), *un terç*, *un quart*, *tres quarts*, *el doble, el triple*, *el 20 % (vint per cent)*, *una desena, una dotzena, un centenar, un miler*.

*Quant costa?* — **Costa dos euros amb cinquanta** (2,50 €). *Val tres-cents euros.*
