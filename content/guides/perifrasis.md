---
title: Perífrasis verbals
exercises: [perifrasis]
---
Una perífrasi = verb auxiliar (+ preposició) + infinitiu / gerundi / participi. Els pronoms febles van davant de l'auxiliar o darrere de l'infinitiu: *ho he de fer* = *he de fer-ho*.

## Obligació i necessitat

| | | |
|---|---|---|
| **haver de** + inf. | obligació personal | **He d'**estudiar. **Hem de** marxar. |
| **caldre** + inf. / **cal que** + subj. | necessitat impersonal | **Cal** estudiar més. **Cal que** estudiïs. |
| **s'ha de** + inf. | impersonal, «cal que tothom» | Aquí **s'ha de** parlar fluix. |

*Tenir que* no existeix en català. *Deure* + infinitiu no és obligació, és **probabilitat**: *Deu ser tard* = probablement és tard.

## Capacitat, voluntat, permís

**poder** + inf. (*Puc entrar?*), **voler** + inf. (*Vull dormir*), **saber** + inf. (saber-ne: *Sé nedar*).

## Fases d'una acció

| | | |
|---|---|---|
| **començar a** + inf. | inici | **Comença a** ploure. |
| **estar a punt de** + inf. | imminència | **Estic a punt d'**acabar. |
| **estar** + gerundi | en curs | **Estic** llegint. |
| **continuar** + gerundi / **seguir** + gerundi | continuïtat | **Continua** plovent. |
| **acabar de** + inf. | fa un moment | **Acabo d'**arribar. |
| **deixar de** + inf. | interrupció | **Ha deixat de** fumar. |
| **tornar a** + inf. | repetició | **Torna a** trucar més tard. |
| **anar** + gerundi | progressió | **Va** millorant. |
| **acabar** + gerundi | resultat final | **Va acabar** plorant. |

Fixa't en els dos sentits d'*acabar*: **acabar de** + inf. = *fa un moment*; **acabar** + gerundi = *al final*.

## Exemples

- No **puc** venir: **haig de** treballar. (*haig de* = *he de*)
- **Acabem de** sopar, ara **estem** rentant els plats.
- **Cal que** portis el passaport. / **Cal** portar el passaport.
- **Deuen** ser les vuit — no, ja **han de** ser les nou.
