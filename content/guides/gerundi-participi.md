## Gerundi

**-ar → -ant, -er/-re → -ent, -ir → -int**: *cantant, perdent, dormint, servint*.

Els irregulars segueixen l'arrel de la 1a persona del plural: **dient, fent, veient, duent, bevent, caient, creient, rient, coneixent, escrivint, vivint, sabent, tenint, venint, podent, volent, sent (essent)**.

Usos:

| | |
|---|---|
| en curs: *estar* + gerundi | **Estic** llegint. |
| acció simultània / manera | Va sortir **cantant**. Ho vaig aprendre **practicant**. |
| *tot* + gerundi (mentre) | **Tot caminant**, parlàvem de la feina. |
| *anar / continuar / seguir* + gerundi | **Va millorant**. **Continua plovent**. |

Dos errors que l'examen busca:

1. **Gerundi de posterioritat** — el gerundi no pot expressar el que passa *després*: ✗ *Va caure, trencant-se la cama* → ✓ *Va caure **i es va trencar** la cama.*
2. **Gerundi com a adjectiu** — ✗ *una caixa contenint llibres* → ✓ *una caixa **que conté** llibres*; ✗ *aigua bullint* → ✓ *aigua **bullent***.

Els pronoms s'hi enganxen: *llegint**-lo**, rentant**-se**, dient**-m'ho***.

## Participi

**-ar → -at, -er/-re → -ut, -ir → -it**: *cantat, perdut, dormit*. Quatre formes: *cantat, cantada, cantats, cantades*.

Irregulars: **fet, dit, vist, obert, cobert, ofert, sofert, escrit, mort, pres, après, comprès, entès, atès, encès, estès, cuit, dut, tret, absolt, resolt, romàs, nascut, viscut, tingut, vingut, pogut, volgut, sabut, begut, rebut, cregut, caigut, estat (ser / estar), sigut (ser, col·loquial)**.

Usos:

| | concordança |
|---|---|
| temps compostos amb *haver* | cap (opcional amb *la / les / el / els*: *l'he vist**a***) |
| passiva amb *ser* | amb el subjecte: *Van ser **rebudes** pel director.* |
| *estar* + participi (estat) | amb el subjecte: *Les finestres **estan** obert**es**.* |
| com a adjectiu | amb el nom: *una carta **escrita** a mà* |
| construcció absoluta | *Acabada la reunió, vam marxar.* |

## Exemples

- **Havent** sopat, vam sortir a passejar. (formal)
- La roba **estesa** encara **està** mullada.
- **Estic** buscant les ulleres — les he **deixades** (deixat) al cotxe.
