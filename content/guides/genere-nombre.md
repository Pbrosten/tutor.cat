## El femení a partir del masculí

| regla | exemples |
|---|---|
| afegim **-a** | noi → noia, senyor → senyora, amic → amiga |
| **-e / -o → -a** | alumne → alumna, mosso → mossa |
| vocal tònica → **-na** | germà → germana, veí → veïna, cosí → cosina |
| **-t → -da**, **-c → -ga**, **-s → -ssa** | nebot → neboda, amic → amiga, gos → gossa |
| **-u → -va** | esclau → esclava, nou → nova, viu → viva |
| **-òleg → -òloga** | psicòleg → psicòloga |
| **-or → -ora** | director → directora (però actor → actriu) |
| invariables | estudiant, artista, periodista, jove, cantant, pacient |
| paraula diferent | home / dona, pare / mare, marit / muller, gendre / nora, cavall / euga |

Paranys de gènere: paraules en **-a** que són masculines (*el dia, el mapa, el problema, el sistema, el clima, el planeta*) i paraules amb un gènere diferent del castellà o l'anglès: **la sal, la calor, la llet, la dent, la sang, la suor, la resta, el front, el llum (l'aparell) / la llum (la claror), el son (l'acte de dormir) / la son (les ganes de dormir), el compte, el senyal, el dubte, els afores, l'avantatge (m.), el costum, el pendent (m.)**.

## El plural

| regla | exemples |
|---|---|
| afegim **-s** | cotxe → cotxes, taula → taules |
| **-a → -es** (amb canvis ortogràfics) | casa → cases, va**ca** → va**ques**, pla**ça** → pla**ces**, ami**ga** → ami**gues**, plat**ja** → plat**ges**, llen**gua** → llen**gües**, pas**qua** → pas**qües** |
| vocal tònica → **-ns** | germà → germans, camió → camions, pa → pans, mà → mans |
| però alguns només **-s** | sofà → sofàs, cafè → cafès, papà → papàs, bebè → bebès |
| masc. en **-s, -ç, -x, -ix, -sc, -st, -xt → -os** | gas → gasos, braç → braços, reflex → reflexos, peix → peixos, disc → discos, gust → gustos (gusts), text → textos (texts) |
| invariables | dilluns, dimarts, dijous, llapis, temps, fons, globus, cactus, virus, atles |
| **-ig → -igs / -jos** | passeig → passeigs / passejos, mig → mitjos |

Els adjectius segueixen les mateixes regles. Els de quatre formes concorden del tot: *bonic, bonica, bonics, boniques; verd, verda, verds, verdes*. Els de dues formes tenen una sola forma per als dos gèneres: *gran/grans, jove/joves, feliç/feliços, difícil/difícils, amable/amables*.
