## Quantitatius

| | formes | observacions |
|---|---|---|
| molt | molt, molta, molts, moltes | concorda: *molta gent, molts llibres* |
| poc | poc, poca, pocs, poques | |
| bastant | bastant, bastants | no té femení |
| tant | tant, tanta, tants, tantes | |
| quant | quant, quanta, quants, quantes | preguntes: *Quantes hores?* |
| massa, força, prou, més, menys | invariables | *massa gent, força llibres, prou temps* |
| gaire | gaire, gaires | només en negatives, preguntes i condicions: *No tinc gaire temps. Tens gaires amics?* |
| gens (de) | invariable | incomptables, negació: *No tinc gens de gana.* |
| cap | invariable | comptables, negació: *No tinc cap germà.* |
| algun | algun, alguna, alguns, algunes | |
| tot | tot, tota, tots, totes | *tot el dia, tota la nit, tots els dies* |
| cada | invariable | *cada dia* |
| uns quants / unes quantes | | alguns |

*Molt* com a adverbi és invariable: *Treballa molt.* / *molt cansada*. Comptable o incomptable: **cap** poma / **gens de** pa; **gaires** pomes / **gaire** pa.

## Comparació

| | | |
|---|---|---|
| superioritat | **més … que** | La Marta és **més** alta **que** jo. |
| inferioritat | **menys … que** | Tinc **menys** feina **que** tu. |
| igualtat (adj./adv.) | **tan … com** | És **tan** alt **com** tu. |
| igualtat (nom/verb) | **tant(a/s/es) … com** | Té **tants** llibres **com** jo. Treballa **tant com** tu. |
| igualtat | **igual de … que** / **el mateix … que** | És **igual d'**alt **que** tu. |

Irregulars: **millor** (més bo), **pitjor** (més dolent), **major / menor** (mida, edat, formal), **superior / inferior**.

Superlatiu: **el/la més … de** — *la ciutat més gran de Catalunya*; **-íssim**: *boníssim, grandíssim, moltíssim*.

Davant d'un nombre: *més **de** cent persones*, *menys **de** deu euros*.

## Exemples

- No hi ha **gaire** gent, però hi ha **massa** soroll.
- No queda **gens de** llet ni **cap** ou.
- Aquest restaurant és **millor que** l'altre, i **molt més** barat.
- Corre **tant com** pot, però no és **tan** ràpid **com** el seu germà.
